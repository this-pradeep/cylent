# PERFORMANCE

The site should be visually ambitious without becoming slow.

---

# Targets

LCP < 2.5s

CLS < 0.1

INP < 200ms

---

# Critical Path

Do not block initial render with:

Three.js
large video
maps
analytics
non-critical scripts

---

# 3D

Lazy load.

Dynamic import.

---

# Images

Use:

AVIF
WebP

Responsive sizes.

Lazy-load below fold.

---

# Video

Use compressed video.

Poster image.

muted

autoplay

loop

playsInline

---

# Fonts

Use next/font.

Limit weights.

---

# SEO

Each page:

title
description
canonical
OpenGraph
structured data where appropriate

---

# Technical SEO

Generate:

sitemap.xml

robots.txt

Use semantic HTML.

---

# Performance Principle

The visual effects should progressively enhance the experience.

The core website should remain fast without them.
