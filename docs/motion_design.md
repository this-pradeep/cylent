# MOTION DESIGN

Motion is one of the primary differentiators.

---

# Motion Philosophy

The website should feel like a sophisticated system executing.

Not a slideshow.

---

# Page Load

Concept:

SYSTEM INITIALIZING

Then:

Logo

Grid

System visualization

Hero typography

CTA

Navigation

Transition should be approximately:

1–1.5 seconds.

Never delay content unnecessarily.

---

# Hero

Create an evolving system visualization.

Potential behavior:

Nodes appear.

Connections form.

System stabilizes.

Headline enters.

The system continues subtly moving.

---

# Scroll

Use GSAP ScrollTrigger.

Scroll can control:

system construction
line drawing
image transitions
typography movement
scale
opacity
horizontal movement
3D camera

---

# Section Transitions

Avoid simple:

opacity: 0 → 1

for everything.

Combine:

clip-path
transform
scale
mask
position
line drawing

---

# Micro Motion

System status:

blinking indicator

Code:

subtle cursor

draw on scroll

increment when entering viewport

---

# Reduced Motion

When prefers-reduced-motion is active:

Disable:

smooth scrolling
parallax
large transforms
3D movement
complex sequences

Content remains fully usable.
