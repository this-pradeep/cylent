# VISUAL DESIGN SYSTEM

## Color

Use the established Cylent palette.

Do not alter brand colors without explicit approval.

---

# Backgrounds

Primary:

Near-black

Secondary:

Deep charcoal

Occasional:

Off-white

---

# Text

Primary:

White

Secondary:

Muted gray

Accent:

Cylent green

---

# Grid

Desktop:

12-column grid

Tablet:

8-column grid

Mobile:

4-column grid

---

# Typography

Use a combination of:

Modern grotesk

- Monospace technical typeface

Example:

Primary:

Geist / Inter / Manrope

Technical:

Geist Mono / IBM Plex Mono / JetBrains Mono

Do not overuse monospace.

---

# Typography Scale

Hero:

clamp(4rem, 10vw, 10rem)

Major headings:

clamp(3rem, 7vw, 7rem)

Body:

16–20px

Technical labels:

10–13px

---

# Technical Labels

Use small uppercase metadata.

Examples:

01 / SOFTWARE ENGINEERING

SYSTEM / 004

STATUS / ACTIVE

---

# Lines

Use thin borders.

Lines can become animation paths.

---

# Buttons

Primary:

Dark / light depending on section.

Include directional arrow.

Example:

START A PROJECT →

Hover:

Arrow movement.

Background transition.

Subtle magnetic interaction.

---

# Cards

Avoid excessive cards.

Use editorial layouts instead.

---

# Borders

Sharp or minimal-radius surfaces.

Do not turn every component into a rounded card.

---

# Green

Accent should appear strategically.

Examples:

● SYSTEM OPERATIONAL

● AVAILABLE FOR PROJECTS

ACTIVE

→

Never use green as a giant background.
